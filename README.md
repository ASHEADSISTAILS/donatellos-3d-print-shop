# Mooresville 3D Prints

Small 3D printing storefront for local Mooresville, NC sales.

The public GitHub Pages site uses these files:

- `index.html`
- `styles.css`
- `products-data.js`
- `script.js`

The kid-friendly editing flow is:

1. Edit `products.py`.
2. Put product pictures in `images/`.
3. Run `python generate_site.py`.
4. Commit and push to GitHub.

See `HOW_TO_EDIT.md` for the beginner version.

## Before Sharing Widely

Update these placeholders in `products.py`:

- `your-email@example.com`
- `https://www.paypal.com/paypalme/YOURPAYPALNAME`
- `https://venmo.com/u/YOURVENMO`
- `https://cash.app/$YOURCASHTAG`
- `https://buy.stripe.com/YOUR_STRIPE_PAYMENT_LINK`

For small orders, local cash or local payment apps usually keep more money in the business than card checkout.
