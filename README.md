# 3D Print Shop

Simple starter website for learning how a shop page works.

The public GitHub Pages site uses these files:

- `index.html`
- `styles.css`
- `products-data.js`
- `script.js`

The beginner editing flow is:

1. Edit `products.py`.
2. Put product pictures in `images/`.
3. Run `python generate_site.py`.
4. Commit and push to GitHub.

See `HOW_TO_EDIT.md` for the kid-friendly version.

Start simple first. Add payment links and delivery rules later.
